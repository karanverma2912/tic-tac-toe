# ❌⭕ Tic Tac Toe (Next Level)

A premium, modern, and responsive version of the classic Tic Tac Toe game.

## 🚀 Features
- **Modern UI:** Dark mode with neon glow effects.
- **Smooth Animations:** Satisfying interactions and transitions.
- **Scoreboard:** Keep track of wins for Player X and Player O.
- **Responsive:** Looks great on desktop and mobile.
- **Clean Code:** Refactored vanilla JavaScript with class-based architecture.

## 🛠️ How to Run
1. Clone the repository.
2. Open `index.html` in your browser.
3. Play!

## 💻 Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
